# 导弹弹道页 `/m/`

独立 React 入口（`m/index.html`、`src/missiles/`），保留科技树 `/` 和 UID 页面 `/u/`。支持最多 4 种同条件比较、发射条件、侧视/俯视/空间投影/速度图、时间游标和动画回放。

## 数据与更新

参数来自 https://github.com/gszabi99/War-Thunder-Datamine 。数据 JSON 保留游戏版本、提交 SHA、源提交时间与每枚导弹的原始文件链接。本次版本 2.59.0.45，提交 e15ef7f810be671a9e70a94dd100ff0b3604131d，90 个参数型号（含变体，并非 90 枚当前可装备导弹）。

手动更新：`node tools/update-air-to-air-ballistics.mjs`。脚本先解析提交 SHA，再以该 SHA 读取清单、武器和版本，避免混入多个快照。完成后才替换输出。原始 rocket 字段保留；`motorStages` 是新推进字段的转换结果。只收录 `bulletType=aam`，不混入空地和地空导弹。不复制 StatShark 的代码、接口结果或图片。

## 模型限制

本页是原创近似模拟，不是游戏发动机或 StatShark 的复刻。使用 0.02 s 步长，0.1 s 图表采样；标准大气、重力、燃烧期间线性质量变化、理想比例导引以及经验阻力模型。阻力公式 `D=0.5*rho*v²*Cd*pi*caliber²/4`；经验 Cd 随马赫数变化并乘以游戏 CxK。这不是已验证的 Gaijin 阻力算法。

旧字段 `force/timeFire/massEnd` 与后缀 1–3 对应推进段；新字段 `propulsionN/impulseN` 转成推进段。新式多个推进器按编号顺序执行，延迟作为相对偏移，不模拟游戏脉冲触发。高抛只加入初段仰角偏置，不复现 PID 和退出逻辑。忽略迎角阻力、舵面气动力限制、外部气压推力修正、捕获条件、干扰与目标机动；目标匀速等高、理想跟踪。缺失比例系数时模型使用 3，缺失过载上限时使用 10 G，未声称为游戏值。20 m 接近阈值用于终止可视化，不代表引信命中。最近距离和终止原因属于模拟结果。

没有通过游戏实测轨迹校准；步长收敛测试验证数值稳定性，不验证游戏精度。

## StatShark 来源调查

2026-10-02 检查 https://statshark.net/missilecalculator 的公开脚本及翻译文件：前端通过 `/api/missiles/searchmissile` 搜索、`/api/missiles/info/{id}?version=...` 读参数、`/api/missiles/CalcMissileRange` 做服务端计算。参数字段与 War Thunder BLK 结构相近，但没有找到明确的上游仓库声明或公开服务端算法，不能断言该站直接使用 gszabi99 仓库。其接口还出现 406，本站不依赖该接口。

## 验证

`npm test` 包含分段推力与燃烧边界、标准大气、游戏制导类别、新推进延迟/质量分离、全数据有限值、积分步长收敛。浏览器检查搜索、选择比较、条件计算、回放、输入校验、主页面入口和 360–2048 px 无页面横向溢出。

## 空对地扩展

/m/?type=agm 直接打开空对地，收录 100 个参数型号，与空空 90 个型号同属 2.59.0.45 快照。包含部分空对海变体和火箭助推制导武器。默认地面静止目标，类型切换重置选择和条件。电视、红外、激光、雷达、半自动指令及手动指令分别标注；实际制导仍是理想跟踪近似。

更新：node tools/update-air-to-ground-ballistics.mjs，读取空空 JSON 的提交 SHA 保证同版本。按飞机/直升机发射武器族筛选，不按通用 atgm_tank 类型全量导入。当前 14 个 YJ-91/Kh-31 参数变体因流量/比冲发动机结构不受支持而遗漏，文件和原因保存于 JSON skipped 字段；页面底部来源说明区块已按需求删除。最大模拟时间 600 s。
